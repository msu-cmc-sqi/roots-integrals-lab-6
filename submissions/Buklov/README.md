# Лаб 6, вариант 9 — Буклов М.А.

Вычисление площади криволинейного треугольника, ограниченного тремя функциями.

## Функции варианта

| Функция | Формула | Реализация |
|---------|---------|------------|
| f1(x)   | 3 / ((x−1)² + 1) | `asm/f1.asm` |
| f2(x)   | √(x + 0.5)       | `asm/f2.asm` |
| f3(x)   | e^(−x)           | `asm/f3.asm` |

Все три функции написаны на NASM (32-bit, cdecl), результат возвращается через FPU-стек (`st0`).

## Алгоритмы

**Поиск корня** (`src/root.c`) — решает уравнение f(x) = g(x) на отрезке [a, b]:
- По умолчанию: **метод деления пополам** (bisection)
- Альтернатива: **метод хорд** (`make METHOD=CHORDS`)

Метод компилируется через флаг `-DMETHOD_CHORDS`, оба варианта живут в одном файле.

**Вычисление интеграла** (`src/integral.c`) — метод средних прямоугольников с оценкой погрешности по **правилу Рунге**: число разбиений удваивается до тех пор, пока |I₂ₙ − Iₙ| / 3 < eps.

## Сборка

```sh
make                  # метод деления пополам
make METHOD=CHORDS    # метод хорд
make clean            # удалить объектные файлы и бинарник
```

Требуются: `gcc` с поддержкой `-m32`, `nasm`, `libc` (32-bit).

## Запуск

```sh
./prog                  # вычислить площадь фигуры
./prog --roots          # x-координаты трёх вершин треугольника
./prog --iterations     # число итераций при поиске каждого корня
./prog --test-root      # тест: sqrt(2) ≈ 1.41421356
./prog --test-integral  # тест: ∫₀¹ x dx ≈ 0.5
./prog --help           # справка
```
