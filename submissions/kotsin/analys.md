Математический анализ
Функции

f1(x) = e^(-x) + 3      (определена для всех x, всегда > 3)
f2(x) = 2x - 2          (линейная)
f3(x) = 1/x             (x > 0, ветвь правее нуля)
Точки пересечения
f2 ∩ f3 — единственная с точным ответом:


2x - 2 = 1/x
2x² - 2x - 1 = 0
x = (1 + √3) / 2 ≈ 1.3660
f1 ∩ f3 — трансцендентное уравнение:


e^(-x) + 3 - 1/x = 0

x = 0.25 → 3.779 - 4.000 = -0.221  (< 0)
x = 0.30 → 3.741 - 3.333 = +0.408  (> 0)

Корень ≈ 0.2678  →  [0.20, 0.35]
f1 ∩ f2 — трансцендентное уравнение:


e^(-x) + 5 - 2x = 0

x = 2.5 → 0.082 + 5 - 5.0 = +0.082  (> 0)
x = 2.6 → 0.074 + 5 - 5.2 = -0.126  (< 0)

Корень ≈ 2.5368  →  [2.4, 2.7]
Форма фигуры
Три угловые точки фигуры (приближённо):

Точка	x	y
A = f1 ∩ f3	≈ 0.268	≈ 3.765
B = f2 ∩ f3	≈ 1.366	≈ 0.732
C = f1 ∩ f2	≈ 2.537	≈ 3.073
В интервале [0.268, 1.366]:  f1 > f3 > f2 → верх: f1, низ: f3

В интервале [1.366, 2.537]:  f1 > f2 > f3 → верх: f1, низ: f2

Формула площади

S = ∫[x_A, x_B] (f1(x) - f3(x)) dx  +  ∫[x_B, x_C] (f1(x) - f2(x)) dx
Раскрыто:


S = ∫[0.268, 1.366] (e^(-x) + 3 - 1/x) dx  +  ∫[1.366, 2.537] (e^(-x) + 5 - 2x) dx
Монотонность для методов Ньютона и хорд
Уравнение	F(x)	F'(x)	Монотонность
f1−f3 = 0	e^(-x)+3−1/x	−e^(-x)+1/x² > 0 на [0.2, 0.4]	возрастает ✓
f2−f3 = 0	2x−2−1/x	2+1/x² > 0 всегда	возрастает ✓
f1−f2 = 0	e^(-x)+5−2x	−e^(-x)−2 < 0 всегда	убывает ✓
Оба метода (Ньютона и хорд) применимы на всех трёх отрезках.

Выбор ε₁ и ε₂
В точках пересечения F(x) = 0, поэтому погрешность в вычислении граней интеграла вносит ошибку площади второго порядка малости (граница интеграла — там подынтегральная функция равна нулю). Это значит, что ε₁ не требует особой строгости.

Практически выбираем:

ε₁ = ε (точность корней = целевая точность)
ε₂ = ε (точность интегралов = целевая точность)
То есть при ε = 10⁻⁴ берём ε₁ = ε₂ = 10⁻⁴, и т.д.
